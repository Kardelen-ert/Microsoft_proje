# Fren Sistemi Ariza Teshis Notlari

Bu belge, ornek bir rayli sistem bakim bilgi kaynagi olarak hazirlanmistir.

Belirti 1: Frenleme mesafesi normalden uzun.

Olasi nedenler:

- Balata asinmasi
- Pnomatik hatlarda basin c kaybi
- Disk yuzeyinde kirlenme veya yaglanma
- Kontrol valfinde gec tepki

Ilk kontrol adimlari:

1. Arac servis moduna alin.
2. Hava basinci degerleri kontrol edilir.
3. Balata kalinligi olculur.
4. Disk yuzeyi gozle incelenir.
5. Fren test kaydi varsa son uclu trend karsilastirilir.

Belirti 2: Fren birakma gecikmesi.

Olasi nedenler:

- Valf mekanizmasinda sikisma
- Geri donus hatti tikanikligi
- Sicakliga bagli mekanik surtunme

Bakim notu:

Ard arda ayni bogide tekrar eden fren gecikmesi varsa yalnizca operator bildirimi ile yetinilmemeli, mekanik ve pnomatik ekip birlikte kontrol yapmalidir.

Emniyet notu:

Fren performansi supheli ise arac normal sefere verilmeden once dinamik test uygulanmalidir.
