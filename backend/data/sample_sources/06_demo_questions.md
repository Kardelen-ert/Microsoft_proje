# Demo Sorulari

Asagidaki sorular sistemin demo ve test asamasinda kullanilabilir:

- Foundry Local internet olmadan calisir mi?
- Grounded cevap ne demektir?
- Sistem kaynak bulamazsa ne yapmalidir?
- Frenleme mesafesi uzunsa ilk kontrol adimlari nelerdir?
- Yolcu bilgilendirme sisteminde ekran donuyor ama anons calisiyorsa ne kontrol edilir?
- SQLite neden yerel RAG projelerinde tercih edilir?
- Chunk boyutu neden retrieval kalitesini etkiler?

Asagidaki sorular ise bilincli olarak cevaplanamaz orneklerdir:

- 2030 yilinda hangi model daha hizli olacak?
- Bu sistemin bulut lisans maliyeti nedir?
- Aracin gercek zamanli GPS konumu nedir?
